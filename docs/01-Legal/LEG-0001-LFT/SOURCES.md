# Fuentes oficiales

## Propósito

Este documento registra las fuentes oficiales utilizadas durante la investigación jurídica `LEG-0001-LFT`.

Solo las fuentes oficiales pueden utilizarse como fundamento para definir obligaciones legales o requisitos obligatorios del producto.

## Prioridad de fuentes

### Nivel A - Obligatorias

- Ley Federal del Trabajo.
- Diario Oficial de la Federación.
- Cámara de Diputados.
- Secretaría del Trabajo y Previsión Social.
- Ley Federal de Protección de Datos Personales en Posesión de los Particulares.
- Normas Oficiales Mexicanas aplicables.

### Nivel B - Complementarias

- Criterios administrativos.
- Guías oficiales.
- Lineamientos emitidos por autoridades competentes.

### Nivel C - Referencia

- Libros especializados.
- Artículos académicos.
- Opiniones doctrinales.
- Plataformas de referencia.

Las fuentes de nivel C pueden orientar análisis, pero no sustituyen el texto legal ni sirven por sí solas para crear requisitos obligatorios.

## Política de citado

Toda regla de negocio debe poder relacionarse con al menos una fuente oficial identificada mediante su código `SRC`.

No se documentarán requisitos obligatorios basados únicamente en opiniones o publicaciones no oficiales.

Cuando una fuente tenga fecha de consulta relevante, deberá registrarse en el documento donde se use o en una futura actualización de esta matriz.
