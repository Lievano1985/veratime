# UX-0003 - Paleta de colores Vera Time

## Colores de marca

| Uso | Nombre | HEX |
| --- | --- | --- |
| Base institucional | Brand Navy | `#021939` |
| Variación institucional | Brand Navy Soft | `#0A2A52` |
| Acción principal | Brand Blue | `#0067E4` |
| Acción destacada | Brand Blue Bright | `#0C86FF` |
| Acento | Brand Sky | `#29B6F6` |
| Hover y profundidad | Brand Deep | `#0D47A1` |

Los botones, enlaces y controles principales usan `Brand Blue`. Sus estados hover usan `Brand Deep`. `Brand Sky` se reserva para acentos, visualizaciones y detalles de apoyo.
